One haiku about debugging, in 5-7-5 syllables — an entry for the
[Seventeen Syllables of Debugging](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605)
bounty on [make.fun](https://make.fun).

```
Cursor cuts the dark,
phantom memory leaks slow,
cat steps on delete.
```

`main.py` validates the haiku against the gate (three lines, 5-7-5
syllables, at most 200 characters) and writes it to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), then reads
the file back to prove it matches exactly.
